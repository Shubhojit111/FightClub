# Third Space — Homepage Reconstruction

Pixel-faithful reconstruction of the [Third Space London](https://www.thirdspace.london/) homepage.

## Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Structure
```
src/
  components/   Navbar, Hero, FeatureCards, LocationFinder,
                ClubsSection, ClassesSection, TrainingSection,
                WellnessSection, PhilosophyStrip, MembershipCTA, Footer
  pages/        Home.tsx
  data/         content.ts
  assets/       photography & imagery
```
